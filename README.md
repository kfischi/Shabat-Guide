# Multi Brawn — מדריך שבת חתן · בר מצוה · חתונה

מוצר דיגיטלי מלא: עמוד מכירה → תשלום ב-Bit → מדריך נעול בקוד גישה.

## מבנה הקבצים

| קובץ | תפקיד |
|------|-------|
| `index.html` | עמוד הבית / מצגת שמובילה לרכישה |
| `pay.html` | עמוד תשלום: כפתור Bit (99 ₪) + הזנת קוד גישה |
| `Guide.html` | **מעטפת המדריך הנעולה** — דורשת קוד גישה (ראי "החדרת התוכן" למטה) |
| `games.html` | עמוד משחקים (בונוס) |
| `netlify/functions/unlock.mjs` | פונקציית שרת שמאמתת את קוד הגישה |
| `netlify.toml` | הגדרות פריסה |

## הזרימה
`index.html` → "רכשי עכשיו 99 ₪" → `pay.html` → תשלום ב-Bit → הזנת קוד → `Guide.html` נפתח.

## ✅ מה צריך לעשות כדי שיעבוד

### 1. החדרת תוכן המדריך שלך לתוך `Guide.html`
הקובץ `Guide.html` שבריפו הוא **מעטפת נעולה ריקה**. כדי להכניס את 25 השלבים שלך:

1. פתחי את קובץ ה-`Guide.html` המקורי שהכנת (עם התמונות).
2. העתיקי את כל בלוק ה-`<style>...</style>` שלו → הדביקי ב-`Guide.html` שבריפו במקום המסומן ב-`<head>`.
3. העתיקי את כל מה שבין `<body>` ל-`</body>` בקובץ המקורי (ה-`div.page-wrap`, כפתורי הוואטסאפ וה-`<script>`) → הדביקי בתוך `<div id="mb-guide" hidden>` במקום המסומן.

> כל המקומות מסומנים בקובץ בהערות בעברית "⬇️ הדביקי כאן ⬇️".

### 2. הגדרת קודי גישה ב-Netlify
1. ב-Netlify: **Site settings → Environment variables → Add a variable**
2. שם: `VALID_CODES`
3. ערך: קודים מופרדים בפסיק, למשל: `AB12CD, 7K9P2Q, MULTI2026`
4. אחרי כל מכירה — את שולחת לקונה אחד מהקודים בוואטסאפ. הקוד מאומת בשרת.

### 3. חיבור הדומיין `guide.multibrawn.co.il` (ידני ב-Netlify)
1. **Site settings → Domain management → Add a domain** → `guide.multibrawn.co.il`
2. ב-DNS של multibrawn.co.il הוסיפי רשומת **CNAME**:
   - שם: `guide`
   - ערך: כתובת ה-Netlify שלך (למשל `your-site.netlify.app`)
3. המתיני להפצת ה-DNS ולאישור ה-SSL האוטומטי של Netlify.

### 4. כפתור באתר הראשי `multibrawn.co.il`
הוסיפי באתר הראשי כפתור עם הקישור:
```html
<a href="https://guide.multibrawn.co.il">המדריך המלא · 99 ₪</a>
```

## ⚠️ על ההגנה — חשוב לדעת
מכיוון שתמונות המדריך מוטמעות בקובץ הסטטי (base64), **שער הקוד הוא הרתעה אפקטיבית אך ניתן לעקיפה** ע"י מי שמבין "הצג מקור". זו הגבלה של אתר סטטי, לא של הקוד.

**שדרוג להגנה אמיתית (אופציונלי, מומלץ בהמשך):**
1. להוציא את התמונות מה-base64 ולאחסן אותן בנפרד (כך הקובץ קל).
2. להעביר את גוף המדריך לתוך פונקציית השרת, שמחזירה אותו רק לאחר אימות הקוד.

כשתרצי — אבצע את השדרוג הזה.
